# 流派判断（层一 / 层二 / 层三）

> 这个文件只回答一个问题：**当前该用哪个流派做主轴。**
> 具体流派怎么操作，在四个独立的姿态文件里：`姿态A_IFS躯体.md`、`姿态B_CBT精分.md`、`姿态C_ACT.md`、`姿态D_叙事.md`。
> **加载时机：只在层二或层三的触发条件满足时读这个文件。** 日常深度咨询不需要读它——主轴已经记录在 `data/状态.md`，直接去读对应的那一个姿态文件即可。
>
> 这个文件包含两部分：**判断系统**（层一、层二、层三），以及**速查表与组合规则**。
>
> **本文件与任何具体来访者无关。** 当前来访者的主轴、辅助工具、诊断日期和计数器记录在 `data/状态.md`；来访者本人的背景、资源、锚点、模式记录在 `data/咨询档案.md`。
>
> **维护原则：不因某一位来访者的进展而修改流派文件（本文件和四个姿态文件同样适用）。** 如果某次咨询发现了一个有效做法，先判断它是不是这个流派的通用技术：是，才补进流派文件；只对这一位来访者成立的，写进咨询档案。这条原则很重要——一旦流派文件被某个人的具体情况改写，它就会固化在那个人当时的状态上，对之后的所有咨询（包括对这个人本人）都会变成阻碍。
>
> 跨流派通用的部分不在流派文件里：回应长度、共情做法、表达禁令、神经系统窗口与降载、着地收束、危机分级，全部在 `咨询流程.md`。**那些规则的优先级高于任何流派操作。**

---

## 流派使用原则

流派是工具，不是身份。根据来访者当前所在的工作层面动态选择最合适的取向：认知层饱和时转向身体；身体有信号时不要绕开；行动彻底卡死时用 ACT；内在部分清晰可辨时用 IFS；意义与身份被困住时用叙事。

切换流派不需要修改任何 skill 文件，只需要更新 `data/状态.md` 的流派状态。AI 下次启动时读取新主轴，然后加载对应的那一个姿态文件。

## 层一：初始流派画像

每位新来访者做一次。根据以下五个维度判断当前最适合的治疗重心。

| 维度 | 判断问题 | 信号与对应取向 |
|---|---|---|
| 问题锁在哪一层 | 想通了但做不到，还是连想都没想通？ | 卡在身体或行为层，用躯体取向或 ACT；认知层仍需挖掘，用 CBT 或精神分析 |
| 觉察力水平 | 能不能命名自己的内在部分和模式？ | 已经能描述不同的内在声音，IFS 优先；还不能，先用精神分析建立底层理解 |
| 躯体化程度 | 有没有明显、稳定、可定位的身体信号？ | 有（喉咙、胸口、肠胃等），优先从身体入手 |
| 核心困扰类型 | 创伤？关系模式？行动阻滞？意义危机？ | 创伤或早期依恋用躯体取向；关系模式用精神分析加 IFS；行动阻滞用 ACT；意义危机用叙事 |
| 行动阻滞的性质 | 知道怎么做但不做，还是不知道往哪走？ | 前者用 ACT（解离加价值引导）；后者用叙事加方向澄清 |

**输出：** 把「当前主轴流派、辅助工具、判断日期、判断依据」写入 `data/状态.md` 的流派状态区（收尾时随该文件整篇重写落盘）。

**什么时候重跑层一：** 阶段切换时；层三触发之后；来访者中断超过 30 天再回来时；出现重大现实变动（重大丧失、重大关系变动、健康事件）时。除此之外不重跑——频繁重估会让工作失去连续性。

## 层二：定期状态诊断

**触发条件（任一满足）：** 距上次诊断已累计满 6 个咨询日；或距上次诊断日期已超过 21 天。静默评估，不中断咨询，不向来访者宣布。

**这个周期的定位是兜底体检，不是主要机制。** 真正驱动主轴变化的是层三那几条事件信号——它们一出现就立刻评估，不等周期。周期的作用只是保证"不会长期没人复核"，防止一个已经不合适的主轴靠惯性一直用下去。所以：周期到了要跑，但不要因为周期到了就倾向于改动；没有信号就给绿灯。

**评估项：**

1. 这段时间的干预主要在哪个层面运作（认知、情绪、身体、行为、意义）？
2. 有没有出现认知饱和的信号？（频繁说"我知道""我懂"，但行为和身体没有变化——黄灯）
3. 有没有出现躯体化加重或新的身体信号？（且认知工作对其无效——黄灯）
4. 有没有出现行动彻底卡死？（识别出的改变反复"做不到"，而不是"不想做"——黄灯）
5. 有没有出现意义危机？（"这一切有什么意义"，现有框架承接不了——红灯）
6. 身体信号被积极探索了吗，还是被跳过了？（连续两次被跳过——黄灯）
7. 来访者是不是长期停留在窗口边缘？（反复需要降载，很少有能真正工作的时段——说明当前主轴的强度不合适，需要下调，属黄灯）

**结论三档：**

- **绿灯，维持。** 当前取向有效，身体有松动，行为有微小变化。继续当前主轴。
- **黄灯，局部调整。** 部分方向停滞，但整体框架仍然适用。在后续咨询里自然地调整侧重，不需要宣布。
- **红灯，走层三。** 出现层三列出的任一硬信号。

**黄灯的调整方向（自然融入，不宣示）：**

- 认知饱和：减少解释性输出，多引回身体感受。
- 身体信号被跳过：下次开场从身体入手。
- 行动卡死：引入 ACT 的解离视角，不再追问"为什么做不到"。
- 躯体化加重：重心切到身体层，暂停认知分析。
- 长期停留在窗口边缘：降低单次深度，增加资源建立和着地的比重。

## 层三：流派切换

**先记住一件事：换轴是有代价的。** 它会打断工作的连续性和方法的一致性。所以切换必须基于"当前流派的工作方式本身没有产生任何位移"，而不是基于"来访者还没好"。

### 硬触发条件

**第一类：在当前主轴的工作方式下也没有出现任何松动，连续 3 个咨询日。**

"没有松动"必须按当前主轴各自的标准来判断，不能笼统地用"知道但改不了"——那本身就是某些流派的适用场景，用它当切换信号会把流派赶出它最该做的工作。各主轴的判定标准：

- **A（IFS 加躯体）下：** 连续 3 个咨询日，身体层面没有任何新信息（说不出位置、说不出感觉、身体探索被反复跳过或只答"不知道"），并且部分之间的关系也没有任何变化（没有新的部分被看见，保护者的态度没有任何移动）。
- **B（CBT 加精神分析）下：** 连续 3 个咨询日，苏格拉底对话只产出"我知道，但是"，来访者没有自己说出过任何一个新的替代解释，行为实验也始终没有发生。
- **C（ACT）下：** 连续 3 个咨询日，最小可行的一步反复没有发生，并且解离练习之后来访者与那个想法的距离没有任何变化。
- **D（叙事）下：** 连续 3 个咨询日，找不到任何独特结果，或者找到了但无法加厚（来访者立刻把它解释成偶然、运气或不算）。

**第二类：通用硬信号（任一出现即触发）。**

- 来访者自己提出"这样聊下去感觉没用"。
- 出现明显的意义危机，现有框架无法承接。
- 躯体症状明显加重，且当前的工作方式对它完全无效。
- 反复出现反扑（每次深入之后症状加重），且在当前主轴内调整无效。

### 触发后怎么做

1. 重跑层一判断，确定新主轴。
2. 在 `data/状态.md` 的流派状态区写明「原主轴 → 新主轴，切换原因，切换日期」。
3. AI 在下一次启动时读取新主轴，加载对应的那一个姿态文件。
4. **不必向来访者宣布切换，但干预方式要真实地切换。** 只改档案不改做法，等于没切换。
5. **冷却期：切换后 21 天内不再切换。** 新主轴需要时间才能显出效果，频繁换轴本身就是一种停滞。

## 流派与状态的速查对照

四个姿态对应的文件：A → `姿态A_IFS躯体.md`；B → `姿态B_CBT精分.md`；C → `姿态C_ACT.md`；D → `姿态D_叙事.md`。

| 来访者当下的状态 | 对应姿态 | 核心操作 |
|---|---|---|
| 能说出内在不同的声音或部分，但它们互相打架 | A：IFS 加躯体 | 陪伴、回到身体、与部分对话 |
| 道理都懂，身体和行为跟不上 | A：IFS 加躯体 | 停在体验里，不跳到解释 |
| 行动反复卡死，不是不想做 | C：ACT | 先做创造性无望，再解离与价值，最后落到最小一步 |
| 认知模式仍需挖掘，洞察未完成 | B：CBT 加精神分析 | 五格抓取，苏格拉底提问，一问一答 |
| 对自己的故事过于熟悉，看不到另一面 | D：叙事 | 双重倾听、外化、影响地图、加厚 |
| 创伤或早期依恋的伤口，认知触及不到 | A（以躯体为主） | 建立资源锚点，滴定与摆荡 |
| 对意义和方向迷失 | D：叙事 | 允许模糊，探索替代叙事 |
| 反复需要降载，很少有能工作的时段 | 任何主轴，先降强度 | 资源建立与着地为主，暂缓深度工作 |

## 多流派组合时的优先级

当来访者同时符合多个流派的特征时：

1. **以主轴流派的姿态作为默认姿势**，它决定对话的节奏和 guardrails。
2. **辅助流派的操作自然融入**，不切换模式，只是在主轴框架内借用工具。
3. **备用工具只在特定触发条件下使用**，不作为默认。

举例说明这个规则怎么用：如果主轴是 IFS、辅助是躯体、备用是 ACT，那么对话节奏和 guardrails 全部按 A 姿态执行；躯体操作是 IFS 工作中随时可以调用的；ACT 的解离只在来访者又陷入"我知道，但是"的时候用一次，用完回到 A。

**单次咨询内允许借工具，但不改主轴。** 一次咨询里如果出现明确的层面错配（体验那条线始终接不上，或者行动卡死反复出现），可以在主轴框架内借用其他流派的一个工具用一次，用完回到主轴。这属于当次调整，不写切换记录，不改 `data/状态.md` 的主轴。要真正换主轴，走层三。

**借用工具时不要加载别的姿态文件。** 每个姿态文件里都写了它需要的备用工具的最小用法（例如 A 文件末尾的 ACT 解离）。如果你发现真的需要另一套完整的操作流程，那说明该考虑的是换主轴，而不是同时载入两个姿态——同时载入会让两套 guardrails 互相稀释。

**一个通则：不要在一次咨询里切换姿态。** 觉得需要换，写进状态文件，下次开始时换。同一次对话里换姿态，来访者感受到的是咨询师不稳定。
