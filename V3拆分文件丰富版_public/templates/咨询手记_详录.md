# 咨询手记·详录（原始证据层）

> 这个文件存放全部逐字咨询记录，是唯一的原始证据层。
> 它默认不加载。只有当某个议题或模式在本次对话里重新出现、需要核对历史原话时，才用下方的「标签索引」定位到日期，用 Grep 拿到行号，再用 Read 的 offset 和 limit 只读那一节，不要整篇读入。
>
> **维护规则（这一层专用）：**
> 1. 逐字手记完整保留，永不压缩成摘要。文件长是完整的证明，不是问题。这里是原始证据，删掉了就永远找不回来。
> 2. 每次咨询结束后，先在下方索引表顶部加一行，再在手记区顶部（时间倒序）新增当天的手记。两处的「日期｜标题」必须逐字一致，写完在同一个文件里核对一次即可。
> 3. 不在这个文件里做去重、合并或删除。结论的演变由《[咨询档案](咨询档案.md)》负责追踪，这个文件只负责逐字留存"发生过什么"。
> 4. 不在这个文件里写状态信息。阶段、优先队列、流派、计数器都只属于《[状态](状态.md)》。
> 5. 每篇手记末尾都要有 `落账` 字段，它只有两个取值：**未落账**、**已落账（日期）**。进行中回写时先写"未落账"，正式收尾把结论归位、状态刷新之后才改成"已落账"。下次启动时会检查最新一篇的这个字段，如果还是"未落账"，就先补一次收尾。字段缺失的历史手记，一律视为已落账。
>
> **单篇手记的结构模板：**
> ```
> ### YYYY-MM-DD｜主题标题
> **情绪轨迹：** …
> **背景事件：** …
> **核心洞察：** *他自己说的：* / *咨询师看见的：*
> **关键行动 / 工具（本次给出）：** …
> **待续（转入开放回合清单）：** …
> **收尾状态：** …
> **落账：** 未落账 / 已落账（YYYY-MM-DD）
> ```
