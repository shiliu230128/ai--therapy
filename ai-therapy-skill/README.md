# AI 心理咨询 Skill

> 一个多流派整合取向的 AI 心理咨询师，支持 IFS、躯体取向、CBT、ACT、叙事疗法，
> 能根据来访者状态自动切换流派姿态。所有咨询数据本地存储，不上传任何服务器。

## 环境要求

- 支持 Skill 机制的 AI 编程助手（Claude Code、Comate 等）
- 对 skill 安装目录有读写权限（用于存储咨询档案）

## 安装

### Claude Code
```bash
git clone https://github.com/yourname/ai-therapy-skill.git ~/.claude/skills/ai-therapy
```

### Comate
```bash
git clone https://github.com/yourname/ai-therapy-skill.git ~/.comate/skills/ai-therapy
```

安装后直接对 AI 说触发词即可，无需额外配置。

## 快速开始

1. 安装后，对 AI 说 **"我想聊聊"** 或直接倾诉你的困扰
2. 首次使用会自动走一个轻松的前采流程（可跳过）
3. 前采后 AI 会创建你的个人咨询档案到 `data/` 目录
4. 之后每次说触发词即可无缝接续

**保存本次咨询：** 说"保存""存档""记录一下"即可强制存档。

## 触发方式

不需要说"启动 ai-therapy skill"，直接说：

- "我最近状态不太好"
- "继续上次的咨询"
- "帮我梳理一下"
- "我有个困扰想聊聊"
- "我感觉……" / "我有点……" / "我最近很……"

## 它能做什么

- **多流派心理咨询：** IFS、躯体取向、CBT、ACT、叙事疗法
- **动态流派切换：** 根据你的状态自动调整咨询姿态，无需手动配置
- **长期记忆：** 跨会话接续，记住你的背景、核心模式、进行中的议题
- **身体层面工作：** 引导你关注身体感受，不只是在认知层面打转
- **完全本地：** 所有数据存在本地 `data/` 目录，不上传任何地方

## 目录结构

```
ai-therapy-skill/
├── SKILL.md                 # 主指令（AI 读取的核心文件）
├── README.md                # 本文件
├── LICENSE                  # MIT
├── .gitignore               # 排除隐私数据
├── knowledge/               # 知识库（方法论，不含个人数据）
│   ├── 流派系统.md           # 流派判断 + 四流派操作姿态
│   ├── 咨询流程.md           # 通用咨询原则
│   └── 前采流程.md           # 新用户前采流程
└── data/                    # 你的个人咨询数据（git 已排除）
    ├── 咨询档案.md            # 稳定背景、当前结论、核心模式
    ├── 咨询手记_详录.md       # 全部咨询对话记录
    ├── counseling_plan_7day.md
    └── EXAMPLE_咨询档案.md    # 模板参考
```

## 隐私

- 所有咨询数据存在本地 `data/` 目录
- `data/*.md` 已被 `.gitignore` 排除，不会被提交到 Git
- 没有任何数据上传到服务器
- 你的咨询档案完全由你掌控

## 重要提醒

这是一个 AI 辅助工具，不能替代专业心理治疗。如果你有自伤/自杀念头，请拨打当地心理危机热线。

## 常见问题

**Q: 怎么切换流派？**
A: AI 会根据你的状态自动判断。如果你想主动提示，可以说"我觉得现在的方向不太对"。

**Q: 换设备了怎么迁移数据？**
A: 把 `data/` 目录的三份文件拷到新设备的相同位置即可无缝接续。

**Q: 可以删除历史记录吗？**
A: 可以。直接编辑或删除 `data/` 下的文件。AI 启动时会自动适应。

**Q: data/ 目录是空的怎么办？**
A: 首次前采时 AI 会自动创建。你也可以参考 `data/EXAMPLE_咨询档案.md` 了解结构。
