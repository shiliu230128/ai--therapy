# AI 心理咨询 Skill

> 一个多流派整合取向的 AI 心理咨询式对话工具，支持 IFS、躯体取向、CBT、ACT 和叙事疗法，并根据来访者状态调整咨询姿态。咨询档案保存在 Skill 安装目录的 `data/` 中，不由本项目上传到任何服务器。

## 这是什么

本项目通过一个 `SKILL.md` 主指令和一组本地知识文件，把支持 Skill 机制的 AI 助手配置为长期使用的心理咨询式对话工具。它可以在每次对话开始时读取近期快速上下文，在需要时检索详细手记，并在咨询过程中更新档案、计划和记录。

它适合长期的自我探索、情绪梳理、心理咨询式对话，以及需要根据历史状态继续对话的个人场景。它不是持证心理咨询师，不能替代心理治疗、医疗诊断、处方或紧急危机干预。

## 环境要求

- 支持 Skill 机制的 AI 助手，例如 Claude Code、Comate 等。
- AI 助手对 Skill 安装目录具有读写权限。档案需要写回安装目录下的 `data/`，否则可能出现保存失败。
- 如果客户端只接受一个孤立的 `SKILL.md`，不会同时复制同级目录，则无法完整使用本项目，应改用支持文件夹安装的方式。

## 安装

### 方式一：使用本地项目文件夹

这是最适合小白的方式：

1. 下载或复制整个 `ai-therapy-skill` 文件夹。
2. 在 Skill 安装或上传界面中，选择这个文件夹本身。
3. 判断是否选对：打开所选目录后，第一层就能直接看到 `SKILL.md`，同时能看到 `knowledge/` 和 `data/`。
4. 完成安装后，打开实际安装目录再次确认这三个项目位于同一层。

正确选择的是：

```text
ai-therapy-skill/
├── SKILL.md       <- 直接位于所选目录下
├── knowledge/
└── data/
```

不要选择 `knowledge/`、`data/` 或它们里面的文件，也不要选择还需要再进入一层才能找到 `SKILL.md` 的目录。不要安装后再把 `data/` 手动挪到桌面或其他位置。

### 方式二：使用命令行复制

把下面的 `/path/to/ai-therapy-skill` 替换成项目的实际路径。

Claude Code：

```bash
mkdir -p ~/.claude/skills
cp -R /path/to/ai-therapy-skill ~/.claude/skills/ai-therapy
```

Comate：

```bash
mkdir -p ~/.comate/skills
cp -R /path/to/ai-therapy-skill ~/.comate/skills/ai-therapy
```

如果项目已经发布到 Git 仓库，也可以使用：

```bash
git clone <仓库地址> ~/.claude/skills/ai-therapy
```

Comate 使用同样的命令，只需将目标路径改为 `~/.comate/skills/ai-therapy`。`<仓库地址>` 必须替换成项目的真实仓库地址，不能直接照抄占位符。

安装后无需额外配置，直接使用触发词即可。

## 快速开始

1. 安装完成后，对 AI 说“我想聊聊”，或直接说出当前困扰。
2. 首次使用时，AI 会先检查 `data/` 中的初始化文件；如果还没有个人档案，会进入前采流程。
3. 前采完成后，AI 会把你的个人背景、当前状态和计划写入 `data/` 下的档案文件。
4. 之后再次说触发词，AI 会从同一个安装目录读取档案并继续对话。

强制保存本次咨询时，可以说“保存本次咨询”“存档”或“记录一下”。自然结束时说“今天先到这里”“差不多了”或“先这样”，也会触发收尾流程。

## 触发方式

不需要说“启动 ai-therapy skill”，直接倾诉或使用类似表达即可：

- “我最近状态不太好。”
- “继续上次的咨询。”
- “帮我梳理一下。”
- “我有个困扰想聊聊。”
- “我感觉……”
- “我有点……”
- “我最近很……”
- “用咨询的方式陪我聊聊。”

如果只想被听见，可以直接说“先听我说，不要急着分析”。

## 它能做什么

- **多流派心理咨询式对话：** 综合使用 IFS、躯体取向、CBT、ACT 和叙事疗法的工作视角。
- **动态流派切换：** 根据当前状态和对话进展调整咨询姿态，无需用户手动修改配置。
- **长期接续：** 通过本地档案保存背景、当前有效结论、核心模式和进行中的议题。
- **身体层面工作：** 在认知分析之外，适时引导用户注意身体感受和身体反应。
- **分层记录：** 用核心档案保存当前有效信息，用详录保存具体对话，用计划文件保存阶段方向。
- **危机优先：** 遇到自伤、自杀或安全风险表述时，停止深度分析，转为确认安全、陪伴和现实求助引导。

## 目录结构

```text
ai-therapy-skill/
├── SKILL.md                       # AI 读取的主指令，Skill 的唯一入口
├── README.md                      # 项目说明和安装说明
├── LICENSE                        # MIT 许可证
├── .gitignore                     # 排除本地咨询数据和系统文件
├── knowledge/                     # 方法论知识库，不存放个人档案
│   ├── 流派系统.md                # 流派判断逻辑和四种流派姿态
│   ├── 咨询流程.md                # 通用咨询原则、表达规范和危机流程
│   └── 前采流程.md                # 新用户首次使用时的前采流程
└── data/                          # 本地咨询数据，随包提供初始占位文件
    ├── 咨询档案.md                # 稳定背景、当前结论、核心模式和快速上下文
    ├── 咨询手记_详录.md            # 详细咨询记录
    ├── counseling_plan_7day.md    # 阶段、优先级和待办计划
    └── EXAMPLE_咨询档案.md         # 档案结构示例
```

根目录下只有一个 `SKILL.md`。`knowledge/` 和 `data/` 是它运行时需要的同级资源，不能拆开安装。

## data 文件和读写位置

Skill 固定使用安装目录下的相对路径：

```text
{SKILL_DIR}/data/
```

因此，`data/` 应和 `SKILL.md` 一起安装在同一个 Skill 目录中。这样档案写入会使用 Skill 目录的权限，能减少写入桌面或其他系统受限目录时失败的问题。

包内已经提供三个初始占位文件，用户不需要手动创建：

- `咨询档案.md`：核心档案和快速上下文。
- `咨询手记_详录.md`：详细记录，默认不全量加载，需要时按标签检索。
- `counseling_plan_7day.md`：阶段和优先级看板。

`EXAMPLE_咨询档案.md` 只是模板参考，不是实际档案，不要把它改名后覆盖真实档案。首次前采完成后，Skill 会在前三个文件中写入真实内容。

## 隐私和数据管理

- 咨询档案默认只保存在本地 Skill 目录的 `data/` 中。
- 本项目没有内置上传咨询数据的功能，也不会主动把档案发送到服务器。
- 使用 AI 助手时，当前对话内容是否会被客户端或其服务商处理，取决于你使用的 AI 产品及其隐私政策；“本地存储档案”不等于“对话模型一定在本地运行”。
- 当前 `.gitignore` 会排除 `data/*.md`，防止真实个人档案被误提交；公开分享项目时不要把含真实个人信息的 `data/` 文件加入提交。
- 更换设备时，先关闭 AI 助手，再备份并迁移 `data/` 下的三个实际档案文件到新 Skill 目录的同一位置。
- 删除或编辑 `data/` 下的文件即可管理历史记录；删除前请先自行备份，因为删除后的内容无法由 Skill 恢复。

## 常见问题

**Q：怎么切换流派？**

A：Skill 会根据状态和对话进展自动判断。如果你觉得当前方向不合适，可以直接说“我觉得现在的方向不太对”或指定希望采用的视角，AI 会据此调整。

**Q：为什么不能只安装 `SKILL.md`？**

A：因为 `SKILL.md` 会读取同级的 `knowledge/`，并把档案写入同级的 `data/`。只安装一个文件会导致知识库缺失，或者无法接续和保存咨询记录。

**Q：`data/` 目录应该单独放在桌面吗？**

A：不应该。当前版本专门把 `data/` 和 Skill 放在一起，以便读写使用同一目录权限。安装后不需要手动挪动文件或修改路径。

**Q：`data/` 里的文件是空的怎么办？**

A：包内的三个文件是初始化占位文件。首次触发咨询后，AI 会检查它们并在前采完成后填充内容；如果文件被误删，重新从项目包复制对应的占位文件即可。

**Q：可以删除历史记录吗？**

A：可以。先备份，再直接编辑或删除 `data/` 下相应内容。AI 下次启动时会根据剩余文件适应当前状态。

**Q：换设备怎么迁移？**

A：在新设备安装同一个 Skill，把旧设备 `data/` 下的三个实际档案文件复制到新安装目录的 `data/` 中，保持文件名和目录层级不变。

## 重要提醒

这是 AI 辅助工具，不是专业心理治疗或医疗服务。如果你有自伤、自杀念头，已经实施伤害行为，或无法保证自己和他人的安全，请优先联系身边可信任的人、当地急救电话或心理危机热线，不要只依赖 AI 对话。
